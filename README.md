# 🏥 AI Smart Clinic – Appointment Booking System

A full stack healthcare management application that allows patients to book appointments, manage schedules, and receive real-time updates.

---

## 🚀 Features

- 🔐 JWT Authentication (Secure Login & Registration)
- 📅 Appointment Booking System
- 👨‍⚕️ Doctor Selection & Specialization
- 📊 Analytics Dashboard (Active, Completed, Deleted)
- 📧 Email Notification (Appointment Confirmation)
- 🧾 PDF Export of Appointments
- 🔍 Search, Filter & Pagination
- 🗑 Soft Delete (History Tracking)
- 🤖 AI-based Priority Prediction (based on symptoms)
- 🌙 Dark Mode UI
